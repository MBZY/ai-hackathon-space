# 申请与审批 · 设计说明（组队双向流 + 联系方式可见性）

> 适用版本：2026-10-13（`?v=20261013f`）
> 相关代码：`src-server/teams/index.js`、`src-server/users/index.js`、`src-server/auth/index.js`、
> `public/js/teams.js`、`public/js/players.js`、`public/js/auth.js`

## 一、双向流总览

组队只保留**一条数据流**：`invites` 表（申请与邀请合并存储，用 `direction` 区分方向）。

```
队长 ──邀请(direction=invite)──▶ 同学         同学 ──申请(direction=apply)──▶ 队伍
   ▲  通知 → 人在「我的空间/队伍页」处理           ▲  通知 → 队长在「队长管理」处理
   └──────────── 接受 / 婉拒 / 撤回 / 拒绝 ────────┘
```

- 入口对称：同学主动找队（申请），队长主动拉人（邀请·名片广场/管理页搜索）。
- 审批人固定：`apply` 由该队队长审批；`invite` 由被邀请人处理。越权一律 403。
- 所有操作落站内通知，避免"石沉大海"。

## 二、状态机（invites.status）

| 状态 | 含义 | 触发 |
|---|---|---|
| `pending` | 待处理 | 发起申请/邀请 |
| `accepted` | 已接受（入队） | 队长通过申请 / 被邀请人接受 |
| `declined` | 已拒绝 | 队长拒绝申请 / 被邀请人婉拒 |
| `cancelled` | 已撤回 | 申请人撤回 / 队长撤回邀请 |
| `expired` | 自动失效 | 该同学加入了别的队伍（或自行建队） |

**一人一队约束**：入队瞬间自动把该同学其余 `pending` 记录置为 `expired`，并通知对应队长「已加入其他队伍」（避免队长对着消失的申请干等）。

## 三、联系方式可见性（本期新增，核心变更）

**默认不公开**。名片广场上任何人都看不到未公开同学的联系方式；由同学在「我的空间 → 我的名片」里勾选
「在选手名片广场公开展示我的联系方式」后才会展示。

| 查看者 | 能否看到对方联系方式 | 说明 |
|---|---|---|
| 本人 | ✅ 始终 | 无论是否开启公开 |
| 队友（同队） | ✅ 始终 | 队内协作需要；以 `team_members` 动态判定 |
| 申请加入的队伍队长 | ✅ 仅该队长 | **申请行为 = 授权**：队长在「待审申请」里可见，用于沟通 |
| 已开启公开的同学 | ✅ 所有登录同学 | 在名片广场可见（游客始终不可见） |
| 其他任何人 / 游客 | ❌ | 只显示「联系方式未公开 · 私信或申请入队后可见」 |

- 数据字段：`user.contact_visible`（布尔，注册默认 `false`）；接口层 `publicUser()` 统一裁剪，
  前端不做安全判断（前端只负责展示差异）。
- 队伍联系方式（`team.contact`）不受影响：由队长建队时主动填写，登录可见，用于对外招募。
- 赛务后台（管理员）不受限制，导出 CSV / 后台视角始终可见全部联系方式。

## 四、UI 入口清单（用户在哪一步做什么）

| 位置 | 角色 | 能做什么 |
|---|---|---|
| 队伍广场 / 队伍详情 | 未入队同学 | 「申请加入」：填期望分工 + 自荐语；申请后按钮变「已申请，等待队长处理」并支持**撤回** |
| 队伍详情（被邀请时） | 被邀请同学 | 「接受邀请加入」/「婉拒」 |
| 名片广场 | 队长 | 每张名片卡上直接「邀请入队」（附言可选），已邀请置灰「已邀请」 |
| 队长管理页 | 队长 | 待审申请（含申请人技能/自荐/联系方式/时间）→ 通过 / 拒绝；已发出的邀请 → 撤回 |
| 我的空间 | 所有人 | 待处理邀请（接受/婉拒）、我的申请（撤回）、最近处理记录（已加入/已拒绝/已撤回/已失效） |
| 通知（铃铛） | 所有人 | 申请/邀请/结果/自动失效的完整通知链 |

不满足申请条件时不再让按钮"静默消失"，会显示原因标签：已加入其他队伍（一人一队）/ 队伍已满员 / 已停止招募。

## 五、通知文案（按事件）

| 事件 | 接收者 | 标题示例 |
|---|---|---|
| 收到申请 | 队长 | 「XX 申请加入「队伍名」」 |
| 收到邀请 | 同学 | 「XX 邀请你加入「队伍名」」 |
| 申请通过 | 申请人 | 「你已加入「队伍名」」 |
| 申请被拒 | 申请人 | 「你加入「队伍名」的申请未通过」 |
| 邀请被接受 | 队长 | 「XX 已加入「队伍名」」 |
| 邀请被婉拒 | 队长 | 「XX 婉拒了「队伍名」的邀请」 |
| 申请被撤回 | 队长 | 「XX 撤回了加入「队伍名」的申请」 |
| 邀请被撤回 | 被邀请人 | 「「队伍名」撤回了邀请」 |
| 自动失效 | 相关队长 | 「XX 已加入其他队伍」（申请/邀请自动关闭） |

## 六、接口速查

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/teams/:id/apply` | 申请加入（重复申请 409） |
| POST | `/api/teams/:id/invite` | 队长邀请（需未入队且无重复 pending） |
| POST | `/api/teams/invites/:id/:action` | `accept` / `decline` / `cancel`（权限按方向判定） |
| GET | `/api/teams/:id` | 详情含 `my_pending_invite` / `my_pending_apply`（当前用户状态） |
| GET | `/api/teams/:id/manage` | 队长管理视图（`pending_applies` 含联系方式、`pending_invites`） |
| GET | `/api/teams/invites/mine` | 我的申请/邀请记录（含历史状态） |
| PUT | `/api/players/me` | 更新名片，含 `contact_visible` 开关 |
